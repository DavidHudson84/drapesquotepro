The mark

An S-fold curtain hanging from its track, seen on the angle. The folds are cut by negative space rather than drawn, which is what lets the mark hold together at favicon size and print in one colour.

Teal on white
White on teal
White on ink

Construction

The lockup is aligned on type metrics, not by eye. Mark height equals the ascender-to-baseline height of the d, so both share a top line and a baseline. The p descender falls below the baseline, as it should. Never reassemble this by hand — use the supplied files.

Lockups

Horizontal is the default. Stacked is for narrow or square placements. The mark alone is only for contexts where the name already appears.

Minimum size

96px wide on screen, 24mm in print. Below that, drop the wordmark and use the app icon or favicon.

Typography

The wordmark is Poppins Medium tracked -2.2%, supplied as outlines — it renders identically with no font file. Interface text uses the system stack for speed; load Poppins only if you want it for headings.

Do and don't

  • Use the supplied lockup files
  • Keep half the mark height clear on all sides
  • Reverse to white on teal or ink
  • Use the mark alone once drapr is established on the page
  • Rebuild the lockup by eye
  • Recolour outside the palette
  • Add shadow, gradient, outline or bevel
  • Stretch, rotate or skew any part
  • Set the wordmark in a different typeface
  • Place on a busy photo without a solid panel
